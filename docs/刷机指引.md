## 刷机流程

测试环境

1. windows 10
2. 瑞星微开发工具 v3.19
3. G98有SPI NOR FLASH(32MB)，默认支持nvme引导

基本步骤：
1. uboot打断，进入命令行

开机按 ctrl+c 打断

![](./images/49693719010500.png)


2. 执行命令扫描nvme

![](./images/49784693310600.png)

此时可能遇到不识别nvme的情况，需要命令触发扫描


```shell
pci enum
nvme scan
```

![](./images/49833990433200.png)

此时可见nvme已经识别

3. 进入loader模式刷机

```shell
rockusb 0 nvme 0
```

![](./images/49881908236800.png)


4. 电脑端用rkdevtool刷机

![](./images/49907086473500.png)



## SPI Nor Flash备份

步骤：
1. 断电
2. 按住recovery按键，保持不动
3. 上电，稍等一会儿，进入loader模式后松开recovery按键


![](./images/50067625193200.png)

4. 获取当前存储，显示为SPINOR。

![](./images/50105577971800.png)

5. 点击读取Flash信息，填写扇区数，默认起始扇区是0

6. 点击导出镜像即可

![](./images/50160767599100.png)

![](./images/50177134629100.png)



## SPI Nor Flash烧写流程

* SPI只有32MB
* 刷机包请在仓库release中获取

下载地址：<https://github.com/yifengyou/BDY_G98_RK3588/releases/download/BYD_G98_SPI_NVME/BYD-G98-SPI-NVME.zip>

步骤：
1. 断电
2. 按住recovery按键，保持不动
3. 上电，稍等一会儿，进入loader模式后松开recovery按键
4. 打开瑞星微开发工具，点击“执行”即可


![](./images/51220343861500.png)

![](./images/51492284453100.png)

![](./images/51631060788800.png)

* SPI烧写速度较慢，请耐心等待。32MB预计3-5分钟。

![](./images/51606944960400.png)

5. 刷机完成，默认重启系统
